# Turtle Gallery · 社团互动精选

本目录包含 14 款实时绘制的互动作品，桌面画廊同时收录项目根目录的 14 款创意原稿，共 28 款。使用 Python 3.9+ 自带的 Turtle 和 Tkinter；作品、配方与巡展无需安装第三方库，可选 PNG 导出需另装 Pillow。互动作品的画面由线条、圆、多边形和数学公式生成。

项目介绍、全部原作与在线预览见[项目首页](../README.md)。本页侧重 14 款互动精选的玩法与代码。

## 开始展示

Windows 可以双击“**双击开始.bat**”。也可以在这个文件夹打开终端：

```powershell
python .\启动展示.py
```

画廊提供“全部作品、互动精选、创意原稿”三个作品集和“浪漫光影”快捷筛选，以及风景动画、几何绘画、趣味挑战、角色与物件、文字实验五个主题。可同时按作品集、主题与关键词筛选，每页最多 6 款。

点击卡片预览开始；“玩法 / 源码”查看操作说明与源文件路径。**1～6** 打开当前页对应位置的作品，**←→** 翻页，**Ctrl+F** 搜索，**F11** 切换画廊全屏。输入搜索时数字键不会启动作品。每款作品使用独立进程，画廊保留原来的筛选条件与页码，可点击“结束作品”关闭当前作品。

第 20 款“温柔便签”需在详情中主动点击“开始作品”，会连续打开最多 50 张便签；画廊中的“结束作品”可以一起关闭。第 22 款“月饼装盒计算”在内置文字窗口输入并回车，无需另外打开终端。

窗口会根据屏幕尺寸选择初始大小，缩略图跟随可用空间调整。进入 01～10 或 25～28 号互动作品后按 **F11 全屏、H 隐藏说明**，适合投影展示。隐藏后再按 H 恢复。

复制到其他电脑时，请保留完整项目，包括根目录的 `run.py`、14 款原稿、本目录及 `docs/assets/originals`。“舞台.py”是互动作品的共用绘图模块；图片仅用于画廊预览，缺失时作品仍然可以运行。推荐从项目根目录运行 `python run.py`，或在 Windows 双击根目录的 `start.bat`。

## 三作品自动巡展

桌面画廊可设置 **25 星空彼岸花 → 26 怦然心动 → 27 星河玫瑰** 循环播放，调整顺序和每件停留时间（10–600 秒，默认 30 秒）。也可以在项目根目录运行：

```bash
python run.py --tour 25,26,27 --seconds 30
```

作品窗口中 **P** 暂停 / 继续巡展、**PgDn** 下一件、**Esc** 结束；画廊也提供控制按钮。点击或使用普通作品按键会暂停自动切换，鼠标悬停不打断。继续时给当前作品完整的停留时间。**空格** 仍控制作品动画；若用空格暂停过动画，先用空格恢复，再按 P 继续巡展。关闭当前作品结束巡展，关闭画廊也会结束作品进程。[完整控制、适用作品与故障说明 →](../docs/EXHIBITION_GUIDE.md)

## 创作面板与配方

25、26 支持横屏 **16:9**、竖屏 **9:16** 和方形 **1:1**。在创作面板选择画幅后，主体和题字会重新排布；可显示 6% 题字安全区，参考线仅供预览。配方记住画幅，旧配方保留原始构图；PNG 按选择的比例保存。[查看实际构图 →](../docs/assets/aspect-compositions.png)

25、26 号作品支持按 **E** 或点击右上角 **创作面板**，打开可滚动的调参窗口。选灵感预设、调整滑块或输入构图种子后，变化会映入作品；“换一幅”更换种子并保留其他参数。彼岸花可以调整花色、绽放速度、星空密度、花瓣卷曲和微风；粒子爱心可以调整颜色、心跳速度、粒子数量和大小。

“保存配方”将这组参数写入 JSON，默认位置为项目根目录的 `creations/`，这个目录不会随 Git 提交。可在相同作品中“载入配方”后重新播放，也可以试试 [蓝紫彼岸花](../examples/recipes/25-blue-night.json) 和 [香槟爱心](../examples/recipes/26-champagne.json)。配方恢复初始构图与设置，不包含当前动画进度、点击记录、图片或视频。

25、26 的 **R** 和面板中的“重播作品”保留当前参数；“恢复默认”才会重置参数。关闭面板后作品继续运行；焦点在面板时按 Esc 关闭面板，回到作品后按 Esc 退出作品。[完整创作步骤与参数范围 →](../docs/CREATION_GUIDE.md)

在 Windows 上还可点击面板中的 **导出当前画面 PNG…**，保存作品的当前帧。先在项目根目录运行 `python -m pip install -r requirements-export.txt` 安装可选依赖。默认保存到 `exports/`；PNG 保留作品题字，去除窗口边框、工具说明、创作面板与巡展条。实际尺寸取决于当前窗口绘图区，以完成提示为准。[导出步骤与限制 →](../docs/EXHIBITION_GUIDE.md#把当前画面保存为-png)

## 几个适合现场讲解的细节

- 烟花：C 选好爱心或金柳再点击发射；F 可以一次发射五束。
- 星系：点选星球后有说明和选中圆环。大小、轨道和速度属于艺术化示意。
- 万花筒：打开即显示完整花瓣；拖动转入手绘。P 影响自动花瓣和后续笔画，已有笔画保留原色。保留最近 900 段笔画，超过后逐步移除最早的部分。
- 锦鲤：除了追逐食物，还会调整方向，避开距离较近的其他鱼。
- 接星星：每颗 1 分，漏接五颗结束；最高纪录保留到当前作品窗口关闭。
- 四季树：G 从树干开始逐层长出分支，适合讲解递归；1～4 可直接比较同一棵树的四季。
- 水母：点击光点停留 6 秒，水母整体缓慢靠近；C 可在蓝紫、珊瑚、翡翠三套配色之间切换。
- 山水：D 在昼夜之间平滑过渡，湖面倒影和舟帆颜色也会随之变化。
- 几何绘图仪：选图案时先显示完整曲线；C 可以清空彩色轨迹并观察画笔重绘，暗色参考线仍保留。
- 打砖块：每块 10 分，共 40 块、3 次球机会。打中球拍不同位置会改变出射方向；A 自动演示会预测落点并瞄准剩余砖块。清空全部砖块即获胜，R 再来一局。

## 推荐的 8 分钟展示顺序

1. 烟花 30 秒：F 齐放开场。
2. 四季树 1 分钟：切换季节，再按 G 展示递归生长。
3. 山水与水母各 45 秒：切换昼夜、添加小舟，再点击光点引导水母。
4. 几何绘图仪 1 分钟：选择图案，按 C 观察画笔路径。
5. 万花筒 1 分钟：请同学画一笔，再换配色。
6. 接星星或打砖块 3 分钟：邀请同学轮流挑战。

## 代码入口与修改位置

各编号文件都可以直接运行，例如：

```powershell
python .\06_四季分形树.py
python .\10_霓虹弹球.py
```

- 01：PALETTES 配色，burst() 花型，location() 粒子运动。
- 02：PLANETS 参数，sphere() 球面，ring() 星环，select() 点选。
- 03：petal() 花瓣控制点，ink_color() 配色，add_ink() 镜像绘画。
- 04：KOI_COLORS 锦鲤配色，draw_fish() 造型，update() 寻食与避让。
- 05：caught() 接取反馈，basket() 篮子，update() 移动与碰撞。
- 06：SEASONS 四季配色，branch() 递归建树，leaf() 花叶。
- 07：THEMES 水母配色，jelly() 伞盖与触手，light() 交互。
- 08：mountains 山形数据，boat() 小舟，pavilion() 亭台，night 昼夜比例。
- 09：PRESETS 图案参数，curve() 内旋轮线公式，prepare() 闭合周期。
- 10：step() 球与砖块碰撞，update() 球拍与自动演示，COLORS 砖块配色。
- 25、26：get_parameters() 读取当前设置，apply_parameters() 应用已验证参数；25 的 build_geometry()、26 的 _make_geometry() 使用独立随机数状态生成构图。
- 创作配方.py：参数范围、预设、格式版本与 JSON 配方读写。
- 创作工坊.py：实时滑块、种子输入、预设、配方文件操作与 PNG 导出入口。
- 作品导出.py：可选 Windows 当前画面捕获、裁切与 PNG 保存。
- 巡展.py：巡展计时、人工接管、作品窗口控制与进程通信。
- 舞台.py：Paint 复用画布对象，Stage 管理缩放、定时动画、全屏和通用按键。
- 作品目录.py：28 款作品的标题、分类、操作说明、预览与源文件路径。
- 启动展示.py：关键词搜索、分类分页、预览卡片、独立进程管理与文字交互窗口。

动画使用 ontimer()，复杂图形通过 Turtle 窗口底层的 Tkinter Canvas 更新已有对象；手绘只追加新线段。弹球采用细分时间步，避免较快移动时穿过砖块。作品运行时无需图像生成或网络服务；菜单预览使用 PNG，25、26 也可通过可选依赖导出当前画面。
