这里有 24 个观察代码如何变成画面的入口。第一次体验先运行 `python run.py`；想直接看某个作品，使用 `python run.py --demo 编号`。

**原作没有统一的暂停、重置和全屏键。** 画廊的停止入口也适用于仍在循环运行的作品。温柔便签隐藏了主窗口，直接运行原文件时，关闭可见便签未必退出进程；推荐从画廊体验。

也可以单独运行原作。文件名含空格时加引号：

```bash
python "import turtle.py"
python "分形树.py"
python "测试.py"
```

月饼计算需要可输入的终端；从画廊打开时使用画廊提供的输入窗口。彩球碰撞沿用原来的运动效果，随机坐标边界已调整为整数以兼容较新 Python。

## 从一个小改动开始

| 想试什么 | 去哪里改 | 观察什么 |
| --- | --- | --- |
| 画一颗不同颜色的心 | [xin.py](../xin.py) 中的 `fillcolor("red")` | 路径相同，填充颜色改变 |
| 让方块排成另一种图案 | [import turtle.py](../import%20turtle.py) 中的 `right(44)` | 旋转角度怎样影响重复与对称 |
| 改变递归圆阵的疏密 | [2.py](../2.py) 中的 `1.5*m` | 子圆到父圆的距离如何改变构图 |
| 长出一棵更舒展的树 | [分形树.py](../分形树.py) 中的 `randint(10,40)` | 分叉角度范围怎样影响树冠 |
| 写下社团自己的问候 | [弹窗.py](../弹窗.py) 中的 `messages` 和 `max_popups` | 用少量便签先观察文字与位置 |
| 让月饼计算更友好 | [测试.py](../测试.py) 中的输入与输出 | 为非整数、负数加入明确的输入提示 |

修改前复制一份作品，方便对比。递归实验先小幅调整：分支数和递归深度会直接影响绘制量。

## 10 款互动展品的修改入口

互动作品位于 `社团展示/`，各自包含场景状态、输入处理和逐帧绘图。它们共用 [舞台.py](../社团展示/舞台.py)，负责窗口、缩放、定时动画和通用按键。[完整操作表 →](../社团展示/README.md)

全部 24 款作品的编号、名称、分类与文件位置统一登记在 [作品目录.py](../社团展示/作品目录.py)。添加作品时同步更新这里，画廊与命令行才能找到它。

| 编号 | 源码 | 适合开始修改的位置 |
| --- | --- | --- |
| 01 | [点击烟花](../社团展示/01_点击烟花.py) | `PALETTES` 配色；`burst()` 花型；`location()` 粒子轨迹 |
| 02 | [旋转星系](../社团展示/02_旋转星系.py) | `PLANETS` 参数；`sphere()` 球面；`ring()` 星环 |
| 03 | [鼠标万花筒](../社团展示/03_鼠标万花筒.py) | `petal()` 花瓣；`ink_color()` 配色；`add_ink()` 镜像笔画 |
| 04 | [互动鱼塘](../社团展示/04_互动鱼塘.py) | `KOI_COLORS` 花纹颜色；`draw_fish()` 鱼形；`update()` 寻食与避让 |
| 05 | [接住星星](../社团展示/05_接住星星.py) | `basket()` 篮子；`caught()` 接取反馈；`update()` 移动与碰撞 |
| 06 | [四季分形树](../社团展示/06_四季分形树.py) | `SEASONS` 四季配色；`branch()` 递归建树；`leaf()` 花叶 |
| 07 | [深海水母](../社团展示/07_深海水母.py) | `THEMES` 配色；`jelly()` 伞盖与触手；`light()` 引导光点 |
| 08 | [山水画卷](../社团展示/08_山水画卷.py) | `mountains` 山形；`boat()` 行舟；`night` 昼夜比例 |
| 09 | [几何绘图仪](../社团展示/09_几何绘图仪.py) | `PRESETS` 图案；`curve()` 内旋轮线公式；`prepare()` 闭合周期 |
| 10 | [霓虹弹球](../社团展示/10_霓虹弹球.py) | `COLORS` 砖块配色；`step()` 碰撞；`update()` 球拍与自动演示 |

星系中的天体大小、距离和运动速度是艺术化示意。几何绘图仪选图案时先展示完整曲线，按 C 后可以观察画笔重绘；这是讲解参数曲线的好时机。

`Paint` 通过 Tkinter Canvas 更新已有图形，`Stage` 使用 `ontimer()` 调度动画。改动一个颜色或图案参数后，先启动对应作品观察效果；改动共用舞台时，再检查多种场景的缩放、输入和退出。

## 一次 8 分钟的社团展示

| 时间 | 作品 | 做什么、讲什么 |
| --- | --- | --- |
| 0:00–0:30 | 01 烟花 | 按 F 齐放，再请观众点一次夜空 |
| 0:30–1:30 | 06 四季树 | 按 1～4 换季，G 观察递归生长 |
| 1:30–3:00 | 08 山水、07 水母 | 切换昼夜、添舟，再用光点引导水母 |
| 3:00–4:00 | 09 几何绘图仪 | 按 C，看圆盘运动如何变成一条曲线 |
| 4:00–5:00 | 03 万花筒 | 请同学拖动一笔，体验镜像与旋转对称 |
| 5:00–7:00 | 10 弹球或 05 接星星 | 轮流挑战；按 R 重新开始 |
| 7:00–8:00 | 13 爱心或 17 原作分形树 | 打开源码，改一个颜色或角度，重新运行 |

展示前先在投影电脑上打开画廊并体验要用的作品。互动展品中按 H 收起说明、F11 全屏；讲解动画时用空格暂停。原作按各自操作说明体验。
