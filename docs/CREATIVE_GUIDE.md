**11～24 的图形模式共用空格暂停、R 重来、H 隐藏说明、F11 全屏、Esc 退出。** R 恢复初始状态；见缝插针会保留配色与本次窗口最高成绩。暂停时点击不触发互动。时钟暂停会定格读数，真实模式下继续播放时重新同步本机时间。每份原作都可关闭作品窗口退出，也可使用画廊的停止入口。

也可以单独运行原作。文件名含空格时加引号：

```bash
python 2.py
python "import turtle.py"
python 哆啦A梦.py
python xin.py
python "分形树.py"
python 见缝插针.py
python 弹窗.py
python "测试.py"
python yeizi.py
python yusan.py
python 风车.py
python 下落的小球.py
python 太极.py
python 时钟.py
```

这十四份原作只使用标准库，图形模式依赖项目中的 `社团展示/` 共用模块，复制时保留完整项目；导入这些文件不会自动打开窗口。圆阵与螺旋默认显示完整构图，按 G 再观察构造过程；螺旋的构造速度范围为 0.25～3 倍。头像的点击目光保持 4 秒后回正，铃铛轻摇 1.4 秒，只有视觉动画、没有声音。

红心的 G 用 4.2 秒重描原圆弧轮廓，↑↓ 将心跳速度限制在 0.25～2 倍；仅在心面完整时接受点击。随机树默认显示完整花冠，N 切换可重现的种子，当前种子显示在说明栏，C 不改变枝条形状。插针有 0.28 秒飞行时间，抵达时才按 8° 间隔判定碰撞；初始 4 针不计分，成功发入 18 针通关，飞行中重复点击不会叠加发射。

温柔便签把原有 26 句问候放进六张卡片，所有操作都在同一作品窗口中完成；点击或 Enter 触发 0.64 秒抬升换句，N 在动画结束后可换整组。月饼默认打开图形界面，总数支持 0～999999、每盒容量支持 1～99，均需输入整数；取消或无效输入会保留原数。G 用 4.2 秒重播图示，最多绘制 3 个整盒、每盒 6 枚样品及 6 枚余数，完整结果与未绘数量始终标明。需要原来的终端问答时，单独运行 `python 测试.py --console`，范围与图形入口一致，按回车开始，在任一提示处输入 q 或关闭输入流（EOF）即可退出；错误输入会提示重新填写。[两款完整玩法与代码入口 →](ORIGINAL_EVERYDAY.md)

彩球使用固定时间步更新运动与近似碰撞；时钟按 D 进入默认 60 倍的演示模式，↑↓ 可在 1～600 倍间调整，再按 D 回到本机时间。

## 从一个小改动开始

| 想试什么 | 去哪里改 | 观察什么 |
| --- | --- | --- |
| 画一颗不同颜色的心 | [xin.py](../xin.py) 中的 `PALETTES`、`heart_point()`、`enamel()` | 两段半圆与两条直线怎样闭合，分层颜色如何形成珐琅光泽 |
| 让方块排成另一种图案 | [import turtle.py](../import%20turtle.py) 中的 `ANGLE_PRESETS`、`square_geometry()`、`fit_geometry()` | 旋转角度怎样影响重复与对称，统一缩放怎样保留边长比例 |
| 改变递归圆阵的疏密 | [2.py](../2.py) 中的 `circle_tree()`、`MAX_DEPTH`、`draw_structure()` | `1.5 * r` 位移与 `r / 2` 半径如何决定相切关系和层级 |
| 让头像看向另一个方向 | [哆啦A梦.py](../哆啦A梦.py) 中的 `pupil_offset()`、`eye_open()`、`draw_bell()` | 椭圆如何限制瞳孔位置，经过时间如何控制眨眼与铃铛摇动 |
| 改变叶片的颜色与露水 | [yeizi.py](../yeizi.py) 中的 `PALETTES`、`draw_leaf()`、`add_dew()` | 圆弧曲面、叶脉与高光如何塑造叶片 |
| 设计另一把雨夜伞 | [yusan.py](../yusan.py) 中的 `SCHEMES`、`rib()`、`scallop()` | 伞骨曲线与伞缘怎样组成分片织物 |
| 设计珠光彩球展台 | [下落的小球.py](../下落的小球.py) 中的 `PALETTES`、`draw_ball()`、`push()`、`collide()` | 多层圆面如何塑造光泽，点击冲量如何改变运动 |
| 调整太极的纸底与环纹 | [太极.py](../太极.py) 中的 `PALETTES`、`fish_path()`、`draw_ornament()` | 外半圆与两段内半圆如何组成双鱼，旋转如何保持形状 |
| 设计自己的表盘 | [时钟.py](../时钟.py) 中的 `PALETTES`、`draw_dial()`、`clock_angles()` | 小时、分钟、秒怎样共同决定指针角度 |
| 改造折纸风车 | [风车.py](../风车.py) 中的 `PALETTES`、`BLADE`、`FOLD`、`blow()` | 一片叶子旋转四次，以及阵风如何改变运动 |
| 长出一棵更舒展的树 | [分形树.py](../分形树.py) 中的 `generate_tree(seed)`、`branch_outline()`、`PALETTES` | 相同种子如何重现分叉，随机角度与减长怎样影响树冠，宽度递减怎样塑造枝干 |
| 调整插针挑战的节奏 | [见缝插针.py](../见缝插针.py) 中的 `FLIGHT_SECONDS`、`CLEARANCE`、`advance()`、`arrive()` | 抵达时刻的转盘角度如何决定碰撞，转速怎样随成功针数增加 |
| 写下社团自己的问候 | [弹窗.py](../弹窗.py) 中的 `MESSAGES`、`PALETTES`、`note_lines()`、`draw_card()` | 同样六张纸笺怎样呈现不同文字与氛围，键盘和点击怎样共享选卡状态 |
| 用礼盒讲整除与余数 | [测试.py](../测试.py) 中的 `packing()`、`parse_number()`、`cake()`、`draw()` | 总数、每盒容量怎样决定整盒和余数，怎样在大量输入时保持绘图数量有界 |

修改前复制一份作品，方便对比。递归实验先小幅调整：分支数和递归深度会直接影响绘制量。

星系中的天体大小、距离和运动速度是艺术化示意。几何绘图仪选图案时先展示完整曲线，按 C 后可以观察画笔重绘；这是讲解参数曲线的好时机。

`Paint` 通过 Tkinter Canvas 更新已有图形，`Stage` 使用 `ontimer()` 调度动画。改动一个颜色或图案参数后，先启动对应作品观察效果；改动共用舞台时，再检查多种场景的缩放、输入和退出。

## 一次 8 分钟的社团展示

| 时间 | 作品 | 做什么、讲什么 |
| --- | --- | --- |
| 0:00–0:30 | 25 星空彼岸花 | 看花在夜空中绽开，点击让流星划过 |
| 0:30–1:30 | 06 四季树 | 按 1～4 换季，G 观察递归生长 |
| 1:30–3:00 | 08 山水、07 水母 | 切换昼夜、添舟，再用光点引导水母 |
| 3:00–4:00 | 09 几何绘图仪 | P 换色、L 比较叠层，再按 G、C 观察滚圆与曲线 |
| 4:00–5:00 | 03 万花筒 | 请同学拖动一笔，体验镜像与旋转对称 |
| 5:00–6:30 | 10 弹球或 05 接星星 | 轮流挑战；按 R 重新开始 |
| 6:30–7:15 | 26 怦然心动 | 请观众点击，观察粒子散开又聚拢 |
| 7:15–8:00 | 13 爱心或 17 原作分形树 | 打开源码，改一个颜色或角度，重新运行 |

展示前先在投影电脑上打开画廊并体验要用的作品。全部作品的图形窗口均可按 H 收起说明、F11 全屏；讲解动画时用空格暂停。各作品专属操作见对应说明。
