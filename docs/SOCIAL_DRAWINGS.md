# 浪漫光影 · 四款短视频风格绘图

[返回项目首页](../README.md) · [在线预览](https://zjh-b.github.io/turtle-gallery/#romantic) · [创作指南](CREATIVE_GUIDE.md)

星空彼岸花、粒子爱心、星河玫瑰和霓光蝶舞是四款可互动的 Python 绘图。它们共用 Turtle / Tkinter 舞台，花瓣、粒子、星星和蝶翼由代码实时生成。下载项目后，可以在桌面画廊选择“浪漫光影”，或直接运行 `python run.py --demo 25` 等命令。

![四款作品的真实运行画面](assets/romantic.png)

| 编号 | 看什么 | 现场操作 | 可以改的代码 |
| --- | --- | --- | --- |
| [25 星空彼岸花](../社团展示/25_星空彼岸花.py) | 六簇卷曲花瓣依次展开，花丝伸向星空 | 点击流星；G 重播绽放；C 换花色；↑↓ 调速 | 改 `THEMES` 的颜色，或调整 `self.florets` 的花序 |
| [26 怦然心动](../社团展示/26_怦然心动.py) | 680 粒星尘沿爱心曲线呼吸、散开、重聚 | 点击散开；C 换色；↑↓ 调整心跳 | 改 `heart_point()` 观察曲线变化；改 `PARTICLE_COUNT` 比较密度与帧率 |
| [27 星河玫瑰](../社团展示/27_星河玫瑰.py) | 贝塞尔曲线勾勒花瓣，分层填色逐瓣长成 | 点击洒星尘；G 重播生长；C 换花色；↑↓ 调速 | 改 `THEMES`，或调整 `self.petals` 中的控制点 |
| [28 霓光蝶舞](../社团展示/28_霓光蝶舞.py) | 镜像蝶翼、翅脉和鳞片随振翅轻轻变化 | 点击引蝶追光；M 切换悬停与漫游；C 换色 | 改 `self.upper` / `self.lower` 的贝塞尔控制点，再看翼形变化 |

四款作品都支持空格暂停、R 重来、H 隐藏说明、F11 全屏、Esc 退出。讲解时可先运行 25 号，等花朵绽放后按空格暂停，继续播放后按 G 重播，说明“时间”如何控制生长；再打开 26 号点击爱心，展示固定数量的粒子如何改变位置后重新聚合。网页预览是运行截图和录制片段，鼠标与键盘互动需要下载并启动 Python 程序。

这些作品按“短视频风格”组织。题材参考可见抖音上的[函数爱心绘图](https://www.douyin.com/video/7164984647821184293)与[Python 万花筒演示](https://www.douyin.com/video/7539477174497037606)；四款作品的程序、场景与交互在本项目中重新设计。这里不使用实时热度排名。
